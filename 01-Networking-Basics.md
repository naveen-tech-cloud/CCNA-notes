# Networking Basics

## Introduction

Networking is the process of connecting two or more devices to enable communication and resource sharing. A network allows computers, servers, printers, smartphones, and other devices to exchange information using standardized communication protocols.

Modern organizations rely on computer networks to provide secure communication, centralized management, internet access, and data sharing across different locations.

# What is a Computer Network?

A computer network is a collection of interconnected devices that communicate with each other using communication protocols. These devices exchange data through wired or wireless transmission media.

A network may consist of:

- Computers
- Servers
- Routers
- Switches
- Firewalls
- Printers
- Mobile Devices
- IoT Devices

---

# Types of Networks

Computer networks are classified according to geographical coverage.

## PAN (Personal Area Network)

A PAN connects personal electronic devices over a very short distance.

Coverage

1–10 meters

Examples

- Bluetooth
- Smartwatch
- Wireless Keyboard
- Mobile Hotspot

---

## LAN (Local Area Network)

A LAN covers a limited geographical area such as a building, office, school, or campus.

Characteristics

- High Speed
- Low Latency
- Privately Owned
- Easy to Maintain

Examples

- Office Network
- School Computer Lab
- Home Network

---

## MAN (Metropolitan Area Network)

A MAN connects multiple LANs across a city or metropolitan area.

Characteristics

- City-wide Coverage
- High Bandwidth
- Connects Multiple Buildings

Examples

- Cable Television Network
- Government Network
- University Campus Network

---

## WAN (Wide Area Network)

A WAN connects multiple LANs over large geographical distances.

Characteristics

- Large Coverage
- Uses ISP Infrastructure
- Connects Different Cities and Countries

Examples

- Internet
- Corporate Branch Networks
- Banking Networks

---

# Network Architecture

There are two primary network architectures.

## Peer-to-Peer (P2P)

Each computer acts as both a client and a server.

Advantages

- Easy Setup
- Low Cost
- Suitable for Small Networks

Disadvantages

- Limited Security
- Difficult Management
- Poor Scalability

---

## Client-Server

A dedicated server provides services to multiple clients.

Advantages

- Centralized Management
- High Security
- Better Performance
- Easy Backup
- User Authentication

Disadvantages

- Higher Cost
- Requires Dedicated Server
- Administrative Expertise Required

# Communication Methods

## Simplex

Communication takes place in only one direction.

Example

- Television Broadcast
- Keyboard

---

## Half Duplex

Communication occurs in both directions, but only one device transmits at a time.

Example

- Walkie-Talkie

---

## Full Duplex

Both devices can transmit and receive data simultaneously.

Example

- Mobile Phone
- Ethernet Communication

# Practical Example

Consider an organization with 100 employees.

All employee computers are connected to a central switch.

The switch connects to a router.

The router provides Internet connectivity through an ISP.

Employees can:

- Access shared files
- Print documents
- Browse the Internet
- Communicate using email
- Access centralized applications
