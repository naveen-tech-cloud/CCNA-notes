# Hot Standby Router Protocol (HSRP)

## Introduction

Hot Standby Router Protocol (HSRP) is a Cisco proprietary First Hop Redundancy Protocol (FHRP) that provides high availability for the default gateway in IP networks. It ensures uninterrupted network connectivity by allowing multiple routers to work together as a single virtual router.

If the primary router fails, the standby router automatically takes over as the default gateway without requiring any changes on client devices. This automatic failover minimizes downtime and increases network reliability.

HSRP is widely used in enterprise networks where continuous connectivity is critical.

# What is HSRP?

Hot Standby Router Protocol (HSRP) is a redundancy protocol that provides a highly available default gateway for hosts on a network.

Instead of configuring the IP address of a physical router as the default gateway, hosts use a Virtual IP Address (VIP). This virtual gateway is shared between multiple routers.

Example

```
          Router 1
         (Active)

             |

      Virtual Gateway

      192.168.1.254

             |

          Router 2
        (Standby)

             |

        LAN Switch

             |

      PC1     PC2
```

---

# Why HSRP is Required

Without HSRP

- Single point of failure
- Network outage if gateway fails
- Manual intervention required

With HSRP

- Automatic gateway failover
- High availability
- Minimal downtime
- Transparent operation for users

---

# How HSRP Works

1. Multiple routers form an HSRP group.
2. One router becomes the **Active Router**.
3. Another router becomes the **Standby Router**.
4. Hosts use the Virtual IP Address as the default gateway.
5. If the Active Router fails, the Standby Router immediately takes over.

---

# HSRP Components

## Active Router

- Forwards all traffic.
- Owns the Virtual MAC Address.
- Responds to ARP requests for the Virtual IP.

---

## Standby Router

- Monitors the Active Router.
- Takes over automatically if the Active Router fails.

---

## Virtual IP Address (VIP)

Shared IP address used by all client devices as their default gateway.

Example

```
192.168.1.254
```

---

## Virtual MAC Address

Automatically generated by HSRP.

Format

```
0000.0C07.ACXX
```

Where **XX** represents the HSRP group number in hexadecimal.

---

# HSRP Router States

HSRP routers transition through the following states:

1. Initial
2. Learn
3. Listen
4. Speak
5. Standby
6. Active

Only one router remains in the Active state.

---

# HSRP Priority

Priority determines which router becomes Active.

Default Priority

```
100
```

Higher Priority wins.

Example

```
Router1 = 120

Router2 = 100

↓

Router1 becomes Active
```

---

# Preemption

Preemption allows a higher-priority router to reclaim the Active role when it comes back online.

Enable Preemption

```
standby 1 preempt
```

Without preemption, the current Active Router remains Active until it fails.

# HSRP Versions

| Version | Features |
|----------|----------|

| HSRP Version 2 | Supports up to 4095 groups, IPv6 support |

Recommended Version

# Cisco Configuration

Configure Interface

```
interface GigabitEthernet0/0

ip address 192.168.1.1 255.255.255.0
```

Configure HSRP

```
standby 1 ip 192.168.1.254

standby 1 priority 120

standby 1 preempt
```

Second Router

```
interface GigabitEthernet0/0

ip address 192.168.1.2 255.255.255.0

standby 1 ip 192.168.1.254

standby 1 priority 100

standby 1 preempt
```

# Advantages

- Provides gateway redundancy.
- Automatic failover.
- High network availability.
- Transparent to end users.
- Easy to configure.
- Supports load sharing with multiple groups.

---

# Limitations

- Cisco proprietary protocol.
- Only one Active router per HSRP group.
- Requires additional configuration.
- Consumes network resources through hello messages.

---

# HSRP vs VRRP

| Feature | HSRP | VRRP |
|----------|------|------|
| Standard | Cisco Proprietary | Open Standard |
| RFC Support | No | Yes (RFC 5798) |
| Default Priority | 100 | 100 |
| Vendor Support | Cisco Only | Multi-Vendor |

---

# Best Practices

- Use HSRP Version 2 for modern networks.
- Configure preemption for predictable failover.
- Set appropriate router priorities.
- Monitor HSRP status regularly.
- Use interface tracking for enhanced reliability.
- Test failover during maintenance windows.
- Document HSRP groups and virtual IP addresses.

---

# Important Notes

- HSRP stands for **Hot Standby Router Protocol**.
- HSRP is a **First Hop Redundancy Protocol (FHRP)**.
- It provides a **Virtual Default Gateway**.
- Only one router is Active at a time.
- The Standby Router automatically takes over upon failure.
- Default Priority is **100**.
- Preemption allows higher-priority routers to regain the Active role.
- HSRP Version 2 supports IPv6 and up to **4095 groups**.

# Conclusion

Hot Standby Router Protocol (HSRP) is a reliable Cisco redundancy protocol that ensures continuous network connectivity by providing a highly available default gateway. Through the use of Active and Standby routers, virtual IP addressing, and automatic failover, HSRP minimizes downtime and enhances network resilience. It remains a fundamental technology in enterprise environments requiring uninterrupted access to network resources.
